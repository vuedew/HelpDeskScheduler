# Help Desk Scheduling Tool

This project is a web-based scheduling system that allows staff to view assigned shifts and submit requests, while administrators manage schedules and approve or deny those requests.

## Features
- Staff dashboard (view shifts)
- Request submission (trade/coverage)
- Admin approvals workflow
- Schedule builder timeline view

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express (conceptual integration)
- Database: MySQL (conceptual design)
